PART 2. THE TECHNICAL RECIPE (for Claude)
-----------------------------------------
1. Animation page: write one self-contained HTML file with a 1280x720 <canvas>.
   - Helper functions: fill(color, pathFn, shadowDepth) draws a shape with a drop
     shadow; sky, hills, ground, water, pine, round tree, fire, stars, moon helpers;
     character functions (e.g. tortoise, fox, person, ghost) with mouth animation when
     talking.
   - Paper grain: a 160x160 random-noise canvas (alpha ~14) used as a repeating pattern
     over every frame, plus a radial vignette.
   - Scenes live in an array S = [{chap, lines:[...], draw(t, lineIndex)}].
     draw() must be deterministic from t (no Math.random in draw) so video frames
     can be rendered one by one.
   - Declare variables before use (avoid const/let temporal dead zone errors).
   - Optionally publish this page too, as an interactive version.

2. Narration (offline neural TTS, because online TTS services are blocked):
   - pip install kokoro-onnx soundfile
   - Download the model from GITHUB (huggingface.co is blocked by the proxy):
     https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/kokoro-v1.0.onnx
     https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/voices-v1.0.bin
   - edge-tts does NOT work here (proxy blocks speech.platform.bing.com).
   - Pull the lines out of the page with Playwright (lines.js), make one WAV per
     line (tts.py), record each duration.

3. Timeline and audio (audio.py): start at 0.8 s, 0.7 s gap after each line, extra
   0.9 s before each new scene for the slide transition. Synthesise music in numpy
   (pentatonic music-box plucks + soft chords + quiet fire crackle), mix at ~0.11
   under the voice, fade in/out, normalise to -1 dB peak. Write timeline.json and mix.wav.

4. Video (render.js): open the page in Playwright with requestAnimationFrame
   disabled, define R(time) that picks the current scene and line from the timeline,
   draws the scene (with slide-in transition), grain, vignette, chapter label and
   word-wrapped subtitle box, and returns canvas.toDataURL('image/jpeg', .9).
   Pipe frames at 24 fps into ffmpeg with mix.wav:
   libx264, crf 20, yuv420p, aac 160k, -movflags +faststart.
   ~4.5 minutes renders in about 5 minutes.

5. Verify: ffprobe duration; ffmpeg volumedetect (expect mean ~ -21 dB, max ~ -1 dB);
   grab 2-3 still frames mid-scene and check the picture matches the subtitle.
   Known bug to avoid: when picking the current line, only update the line index when
   time >= that line's start, or visuals lag one line behind the caption
   (fixed version is in render.js below).

6. Send the MP4 with SendUserFile from the scratchpad. Do not leave it in the repo.

For vertical 9:16: set canvas to 720x1280, W/H accordingly, move characters to the
lower half, enlarge subtitles (~34px, max width ~620px).

===== tts.py =====
import json,soundfile as sf
from kokoro_onnx import Kokoro
k=Kokoro('voice/kokoro-v1.0.onnx','voice/voices-v1.0.bin')
L=json.load(open('lines.json'));out=[]
for si,s in enumerate(L):
  for li,t in enumerate(s['lines']):
    a,sr=k.create(t.replace('"','').replace('“','').replace('”',''),voice='bf_emma',speed=0.95,lang='en-gb')
    f=f'n_{si}_{li}.wav';sf.write(f,a,sr);out.append([si,li,len(a)/sr]);print(f,len(a)/sr,flush=True)
json.dump(out,open('durs.json','w'))

===== audio.py =====
import json,numpy as np,soundfile as sf
D=json.load(open('durs.json'));SR=24000;tl=[];t=0.8;prev=-1
for si,li,d in D:
  if si!=prev and prev!=-1: t+=0.9
  tl.append([si,li,t,t+d]);t+=d+0.7;prev=si
T=t+2.5;json.dump({'tl':tl,'T':T},open('timeline.json','w'))
n=np.zeros(int(T*SR))
for si,li,a,b in tl:
  x,_=sf.read(f'n_{si}_{li}.wav');i=int(a*SR);n[i:i+len(x)]+=x
m=np.zeros_like(n);rng=np.random.default_rng(1)
def pl(f,t0,v,dur):
  i=int(t0*SR);k=np.arange(int(dur*SR));
  if i>=len(m):return
  env=np.exp(-k/SR*3.2/dur*1.5)*np.minimum(1,k/(0.01*SR));w=(2/np.pi)*np.arcsin(np.sin(2*np.pi*f*k/SR))
  e=min(len(m),i+len(k));m[i:e]+=(v*env*w)[:e-i]
notes=[0,2,4,7,9,12,14,16];chords=[[0,4,7],[9,12,16],[5,9,12],[7,11,14]];b=220;step=0;t0=0
while t0<T:
  for i in range(8):
    w=t0+i*.35;nn=notes[(step*3+i*5+i%3)%8]
    if i%2==0 or rng.random()<.4: pl(b*2*2**(nn/12),w,.3,1.6)
    if i==0:
      for c in chords[step%4]: pl(b/2*2**(c/12),w,.16,2.6)
  step+=1;t0+=2.8
cr=rng.standard_normal(len(m))*0.004;pops=rng.random(len(m))<0.0006;cr[pops]+=rng.standard_normal(pops.sum())*0.25
m=m*0.11+cr*0.5
fade=np.minimum(1,np.minimum(np.arange(len(m))/SR/2,(len(m)-np.arange(len(m)))/SR/2.5));m*=fade
out=n*0.95+m;out/=max(1,np.abs(out).max()/0.95)
sf.write('mix.wav',out,SR);print(T)

UPDATE (v2): SMOOTH, CONTINUOUS MOTION. USE render2.js INSTEAD OF render.js
----------------------------------------------------------------------------
- No paper flip. Scenes crossfade over 1.6 s with smootherstep easing while both
  keep animating, so motion never stops.
- Continuous camera: a slow push-in across each scene (zoom 1.05 to 1.12) plus
  gentle handheld drift and tilt driven by simplex noise.
- Ambient layers: paper clouds and flapping birds in daytime scenes, glowing
  fireflies at night, dust motes by day.
- Chapter label glides in, captions fade and rise, 30 fps, crf 19.
- Needs simplex-noise (MIT, github.com/jwagner/simplex-noise.js):
    mkdir lib && cd lib && npm init -y && npm i simplex-noise@4.0.3
- Preview single frames first:  node render2.js $(pwd)/page.html 103.1,85
- Full render:                   node render2.js $(pwd)/page.html

import json,re,soundfile as sf
from kokoro_onnx import Kokoro
K=Kokoro('../voice/kokoro-v1.0.onnx','../voice/voices-v1.0.bin')
F=json.load(open('fil.json'));FL={k.lower():v for k,v in F.items()}
rx=re.compile(r'\b('+'|'.join(map(re.escape,sorted(F,key=len,reverse=True)))+r')\b(’s)?',re.I)
YEARS={'1521':'fifteen twenty-one','1565':'fifteen sixty-five','1980':'nineteen eighty'}
PH=['apple','zebra','violin','marble','tulip','walrus','pepper','candle','rocket']
def spoken(t):
  t=t.replace('"','').replace('“','').replace('”','')
  for y,w in YEARS.items(): t=re.sub(r'\b'+y+r's?\b',w,t)
  t=t.replace('Kalibo, Aklan','Kalibo Aklan').replace('Lucban, Quezon','Lucban Quezon')
  return t
def ph(t):
  t=spoken(t);subs=[]
  def rep(m):
    i=len(subs);subs.append(FL[m.group(1).lower()]+('z' if m.group(2) else ''));return PH[i]
  t2=rx.sub(rep,t);whole=K.tokenizer.phonemize(t2,'en-us')
  for i,ipa in enumerate(subs):
    w=K.tokenizer.phonemize(PH[i],'en-us').strip(' .')
    if w not in whole: raise SystemExit(f'placeholder {PH[i]} ({w}) not found in: {whole}')
    whole=whole.replace(w,ipa,1)
  return whole
L=json.load(open('lines.json'));res=[];dump=[]
for si,s in enumerate(L):
  for li,t in enumerate(s['lines']):
    p=ph(t);dump.append(f'{si}.{li}: {p}');a,sr=K.create(p,voice='af_heart',speed=0.92,is_phonemes=True)
    sf.write(f'n_{si}_{li}.wav',a,sr);res.append([si,li,len(a)/sr])
