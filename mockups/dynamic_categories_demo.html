How dynamic categories work

One shared category list feeds the report for every user. Edit a value or a label on the left, then run the Monday refresh: both users' filters change together, while each keeps their own ticks. Values are test data (Main Category = Country, Sub Category = Department Name).

Maintained by one owner (your team or RAC)

Category list

One row per department code. Click a category cell to edit it; edited cells turn red until the refresh. Users never edit this list.
