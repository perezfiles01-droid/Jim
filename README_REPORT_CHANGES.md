# Report changes: where they go

From 25 Nov 2026, every change to the EDRMS Utilization Report is made in the
**developers' code port**. The latest is version 1.0.0.6, delivered as
`edrms-utilization-report.sppkg` and `UtilizationReport-src.zip` in the
requester's Google Drive.

How to pick it up, build it, check it and deliver it: `DEV_SOURCE_GUIDELINES.md`.
Colours, fonts and icons: `BRANDING.md`. Progress and decisions: `PORT_PLAN.md`.

The prototype (`index.html`), the Floot app and the 1.0.x web part are no longer
updated, unless the requester asks for one of them by name.
