3. TECHNICAL FACTS LEARNED THE HARD WAY (DON'T REDO THESE MISTAKES)
======================================================================
- SharePoint's script policy uses a nonce plus 'strict-dynamic'. A
  <script src> written in markup is blocked. ReportHost adds every script
  with doc.createElement('script'), async=false, into a srcdoc iframe.
- internalModuleBaseUrls[0] has NO trailing slash in this tenant. The code
  adds one; without it every script returned 404.
- SharePoint moves the web part, which reloads the iframe. Scripts are
  reinjected on every load, marked with data-edrms-loaded.
- Assets are ASCII only: \u escapes in JS, entities and CSS escapes in the
  markup, and a BOM on the vendor libraries. Anything else turned into
  mojibake.
- Scaling: the report is laid out on a fixed canvas (standard 1920 / large
  1536, the default / xlarge 1280) and scaled to the container width. No
  browser-zoom factor in SharePoint; it caused overflow.
- Sizing modes: 'content' (the default, iframe as tall as the report, one
  page scroll), 'window' and 'fixed'.
- The sticky sidebar is emulated with --edrms-stick translateY. The #side
  children need flex-grow:0.
- Header strip hidden (header{display:none}). The Export to PDF button
  (.dx-btn) and the "EDRMS Reporting Suite" card (.crumb) move into
  .edrms-tools on the first #view .band (class edrms-top). The menu button
  sits at the band's left. switchTo() redraws #view, so all three are held
  by reference and put back by a MutationObserver.
- Menu button: toggles html.edrms-side-closed, remembered in localStorage
  key 'edrms-sidebar-closed'. The icon is a sidebar-panel SVG: the left
  pane is shaded and the arrow points left when open; the arrow flips when
  closed.
- Exports: html2canvas 1.4.1, jsPDF 2.5.1 and SheetJS 0.18.5 (from cdnjs in
  Floot, bundled in SPFx). The PDF clone sets zoom to 1 and width to
  1920px, draws the conic-gradient donut as an image, and swaps date inputs
  for text.
- Row heights: .sites-split rows had a fixed height of 56px; now 34px with
  the code and name on one line.
- SharePoint "Site access" panel: on this tenant it sometimes draws no Add
  button. Use the classic page instead:
  /sites/EDRMSUtilsample/_layouts/15/user.aspx, then Grant Permissions.
