# Utilization Report source register

Every data source for the Utilization Report is listed here, whether or not
its file is in the repo yet. **Check this register before saying a figure has
a source or has none.**

Rules:

- A raw file goes in `sources/<tenant>/`, named `<what>_<YYYY-MM-DD>.<ext>`
  with the date it was exported. Do not edit raw files; derived files say so.
- Every file gets a row below: what it holds, its row count and the columns
  that matter, each counted (filled rows), not assumed from the header.
- A source we know exists but do not hold is listed under **Missing**, with
  who has it. A source that is listed but not in the repo cannot be relied on.
- The older `evidence_*.csv` files stay at the repo root because `STATUS.md`
  and the checks cite them by path. They are registered here as well.
